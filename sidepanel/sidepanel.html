How to use Flow Queue

1. Open a Google Flow project.
(The URL should look like labs.google/fx/tools/flow/project/…)

2. Add your prompts to the prompt queue-one per line—then click Run queue.

Optional · timing

Minimum and maximum pause (seconds) set how long Flow Queue waits between prompts. We pick a random wait inside that range each time. Adjust only if you want longer or shorter gaps; the defaults are fine for most uses.
